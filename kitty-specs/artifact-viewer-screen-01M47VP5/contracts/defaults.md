# Contract: new default modules (`src/defaults/`) and logic (`src/logic/`) of this mission

Plain TypeScript, no I/O, no DOM. Reused by import, not redeclared: `lookup`, `LabelHooks`, `StateBadge`, `BadgeTone`, `relativeTime`, `resolveActivity`, `JUST_NOW_TEXT` and the other time words of #4, `REVIEW_CYCLE_ARTIFACT_KIND` of #5 (merged, Base A). This mission adds NO time logic: every "modified" text goes through `resolveActivity`. The five default modules below are re-exported from `defaults/index.ts` (the one edit of that file, IC-02; `index.ts` is the sixth file of the directory, not a sixth module). Every table is a `Readonly<Record<string, T>>` read through `lookup`, raw fallback (FR-030). English copy only. Nothing here is a lane or phase.

`ArtifactVocabulary` (`logic/artifact-types.ts`, IC-02; the one optional `vocabulary` property, A-9) is composed of these exports: the kind table (`ARTIFACT_KIND_WORDS`: label and icon), `WORK_PACKAGE_LINK_KINDS`, `WP_CONTAINER_SEGMENT` with `TOKEN_SEPARATOR`, `MARKDOWN_MEDIA_TYPE`, and `MARKDOWN_BUDGET` (FIVE groups; the copy of `artifact-copy.ts` is NOT a member (PLAN-FRESH4-007 (b)): its strings are read from `defaults/` directly and a string-level override goes through the four `labels` hooks of the types row, `kind`, `refusal`, `mediaType` and `size`; the copy is English constants from `defaults/` and no new hook is added); the default vocabulary is built from `defaults/` (nothing duplicated). A partly filled `vocabulary` is completed PER GROUP against `defaults/` (PLAN-FRESH3-004 (b)): the five groups are the kind table, `WORK_PACKAGE_LINK_KINDS`, the container segment with the token separator, `MARKDOWN_MEDIA_TYPE` and `MARKDOWN_BUDGET`; a group that is present is used as given, whole and not merged key by key, a group that is absent takes the `defaults/` value, and `{}` equals `null`. Everything else of `defaults/` (the copy of `artifact-copy.ts`, the refusal table, `MEDIA_TYPE_WORDS`, `EXTERNAL_LINK_SCHEMES`, `BIDI_CONTROL_CODE_POINTS`, the size unit table) is NOT a member: it is overridden, where it can be, through `labels`.

Vocabulary argument: ONLY the functions that read a member of `ArtifactVocabulary` take the resolved vocabulary (or the member they need) as an explicit argument with the `defaults/` value as default: `buildArtifactTree` and `resolveArtifactFacts` (the kind table), `markdownFor` (the media type), `buildMarkdownModel` (the budget), `matchWorkPackage` (the link kinds, the container segment, the token separator), and `resolveArtifactView` for any member IC-02 finds it reads. `formatArtifactSize`, `resolveArtifactRefusal` and `countBidiControls` read tables that are not members and take no `vocabulary` (`countBidiControls` keeps its own optional code-point argument). The screen resolves the vocabulary once per update, completing it per group (above). Each function that takes it is unit-tested with and without it; the per-group completion (five groups) has its own cases, and a type-level case shows that `copy` is not a member of `ArtifactVocabulary`.

The data-driven gate reads the twelve kinds from `schemas/ArtifactKind.yaml` and the seven codes from `schemas/ArtifactRefusalCode.yaml` (count guards 12 and 7), so `ARTIFACT_KIND_WORDS` and `ARTIFACT_REFUSALS` are the only homes of those words.
